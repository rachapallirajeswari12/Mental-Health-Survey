# 🧠 Mental Health in Tech Survey

## 📌 Project Overview

This project analyzes the **Mental Health in Tech Survey** dataset to understand mental health treatment patterns, employee experiences, and workplace support factors in the technology industry.

The project combines **Exploratory Data Analysis (EDA)** with an interactive **Streamlit dashboard** to present meaningful insights through data visualizations.

## 🎯 Objectives

* Analyze employee mental health treatment patterns.
* Understand the relationship between family history and treatment.
* Study the relationship between work interference and treatment.
* Explore workplace mental health benefits and support programs.
* Analyze treatment patterns across age groups, gender, remote work, and countries.
* Build an interactive dashboard for easy data exploration.

## 📊 Dataset

The dataset contains **1,259 survey responses** related to mental health in the technology workplace.

Key fields include:

* Age
* Gender
* Country
* State
* Family History
* Treatment
* Work Interference
* Remote Work
* Tech Company
* Mental Health Benefits
* Care Options
* Wellness Program
* Seek Help
* Anonymity
* Mental Health Consequences
* Physical Health Consequences
